# Store Listing Draft

## App name
Document Scanner — Scan to PDF

## Short description
Scan documents, crop pages and create high-quality PDFs offline.

## Key features
- Document scanning with CameraX + OpenCV
- Automatic document boundary detection
- Manual four-corner crop
- Multi-page documents
- Rotate, grayscale and enhancement tools
- A4, Letter and other PDF page sizes
- High-quality PDF/JPEG export
- Password-protected PDF
- Local saved scans
- Share documents
- No AI/ML
- No cloud sync

## Important
Final store claims must match the features actually verified in the release build.
